The passphrase is verified by re-deriving a scrypt key and comparing it in constant time; nothing is stored, and a wrong guess costs the same as a correct one. After {{ max_attempts }} failures the address is locked out for a few minutes. If you have forgotten the passphrase there is no recovery: the vault is encrypted, so the only option is to delete it and start a new watchlist.

What signing in does

  • Runs a breach check on your watchlist — every email, phone number and handle is re-checked against the configured sources each time you log in.
  • Opens the dashboard: scans, coverage, and the watchlist itself (masked).
  • Keeps secrets off disk. Passwords are checked in memory with k-anonymity and never stored; only a keyed fingerprint is.
